# بکاپ مکادیز در Google Sheets — راهنمای نصب

این اسکریپت، دادهٔ پنل مکادیز را در **همان Google Sheet شما** ذخیره می‌کند و
**همهٔ شیت‌ها را خودکار می‌سازد، راست‌به‌چپ و مرتب می‌کند**.

فایل اسکریپت: [`Code.gs`](Code.gs)

شیت مقصد (از پیش در کد تنظیم شده):

```
https://docs.google.com/spreadsheets/d/1iFN8qHAXws8UAu-GVRkGsFqO4pqhwRwkBlyaiHBa5_A
```

---

## ۰) شیت‌هایی که خودکار ساخته می‌شوند

| شیت | محتوا |
|---|---|
| **داشبورد** | ۱۹ شاخص: تعداد و مبلغ سفارش‌ها، پرداختی، ماندهٔ مطالبات، مشتریان، ساعت‌کار، دستمزد کل و تعداد هر وضعیت |
| **سفارش‌ها** | کد، تاریخ شمسی، مشتری، شرکت، خدمت، ساعات، نرخ، مبلغ، پرداختی، مانده، موعد، وضعیت (رنگی)، اولویت، منبع، توضیح، فایل‌ها |
| **پرداخت‌ها** | تاریخ، کد سفارش، مشتری، مبلغ، روش پرداخت، یادداشت |
| **مشتریان** | مشخصات + تعداد سفارش + مبلغ کل + پرداختی + مانده |
| **خدمات** و **نرخ‌نامه** | لیست خدمات و پله‌های نرخ ساعتی |
| **کاربران** | نام، نام‌کاربری، نقش، تماس، شماره حساب، وضعیت، آخرین ورود |
| **فعالیت‌ها** | انواع فعالیت و نرخ ساعتی |
| **ساعت‌کار** | هر جلسه: تاریخ، کاربر، فعالیت، پروژه، شروع، پایان، مدت، نرخ، دستمزد |
| **گزارش دستمزد** | تجمیع ساعت و دستمزد هر کاربر به تفکیک فعالیت + ردیف «جمع کل» |
| **پروژه‌ها**، **تنظیمات**، **لاگ** | نمونه‌کارها، تنظیمات مجموعه، تاریخچهٔ هر بار بکاپ |
| **کد بکاپ** | جای چسباندن کد بکاپ + راهنمای کوتاه |

هر شیت: سرصفحهٔ سرمه‌ای ثابت (Freeze)، فیلتر، نواربندی ردیف‌ها، عرض ستون‌های تنظیم‌شده،
اعداد سه‌رقم‌جدا و تاریخ شمسی. سفارش‌ها بر اساس تاریخ نزولی، پرداخت‌ها و ساعت‌کار هم نزولی مرتب می‌شوند.

## ۱) نصب (یک بار)

1. Google Sheet را باز کنید → منوی **Extensions ← Apps Script**.
2. فایل نمونه را پاک کنید و **کل محتوای [`Code.gs`](Code.gs)** را جای آن بچسبانید.
3. **ذخیره (Ctrl+S)** و بعد صفحهٔ شیت را **Refresh** کنید.
4. بالای شیت منوی **«بکاپ مکادیز»** ظاهر می‌شود.
5. بار اول که یکی از گزینه‌ها را می‌زنید، گوگل اجازه می‌خواهد؛ **Review permissions ← حساب خودتان ← Allow**.
   (پیام «Google hasn’t verified this app» طبیعی است؛ چون اسکریپت مال خودتان است:
   Advanced ← Go to project (unsafe).)

## ۲) وارد کردن داده — سه راه

### راه ۱: چسباندن کد بکاپ در شیت (ساده‌ترین)

1. در پنل: **تنظیمات ← داده‌ها ← «کد پشتیبان (Google Docs)» ← «کپی کد»**.
2. در شیت، تب **«کد بکاپ»** → سلول **A3** → **Ctrl+V**.
3. منوی **بکاپ مکادیز ← «۲) وارد کردن کد از شیت «کد بکاپ»»**.

> محدودیت: هر سلول گوگل‌شیت حداکثر ۵۰٬۰۰۰ کاراکتر می‌پذیرد. کد نمونهٔ پنل ~۸٬۰۰۰ کاراکتر است؛
> برای داده‌های خیلی بزرگ از راه ۲ یا ۳ استفاده کنید.

### راه ۲: فایل متنی در Drive

1. در پنل: «دانلود فایل متنی» (همان پنجرهٔ کد بکاپ) → فایل `mecades-backup-code-…txt`.
2. فایل را در Google Drive آپلود کنید.
3. منوی **بکاپ مکادیز ← «۳) وارد کردن از فایل متنی در Drive»** → نام فایل را وارد کنید.

### راه ۳: اتصال زندهٔ پنل (یک دکمه، بدون کپی)

1. در Apps Script: **Deploy ← New deployment ← Web app**
   - *Execute as*: **Me**
   - *Who has access*: **Anyone**
   - **Deploy** → آدرس `…/exec` را کپی کنید.
2. در شیت: **بکاپ مکادیز ← «درباره»** → «توکن اتصال» ساخته و نمایش داده می‌شود.
3. در پنل: **تنظیمات ← همگام‌سازی Google Sheets** → آدرس `…/exec` و توکن را بگذارید →
   **ذخیرهٔ آدرس** → **ارسال به Google Sheets**.

از این به بعد هر بار یک دکمه، کل داده‌ها را به شیت می‌فرستد (بدون کپی/پیست).
پنل تا وقتی این آدرس خالی باشد هیچ درخواستی به بیرون نمی‌فرستد.

## ۳) نکات امنیتی

- **توکن اتصال** جلوی نوشتنِ ناخواسته توسط دیگران را می‌گیرد؛ آن را با آدرس Web App فقط در اختیار خودتان بگذارید.
  اگر توکن در اسکریپت ساخته شده باشد، هر درخواست بدون توکن رد می‌شود.
- هش رمزها به‌طور پیش‌فرض در شیت **نوشته نمی‌شود** (برای فعال کردن: در بالای `Code.gs`
  مقدار `INCLUDE_PASSWORD_HASHES` را `true` کنید).
- شیت را «خصوصی» نگه دارید؛ نام مشتریان و مبالغ قرارداد داخل آن است.
- اسکریپت **فقط می‌نویسد**؛ هیچ داده‌ای را از شیت به پنل برنمی‌گرداند (بازیابی پنل از راه «کد پشتیبان» است).

## ۴) عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| منوی «بکاپ مکادیز» نیست | صفحه را Refresh کنید؛ اگر نبود، اسکریپت را ذخیره و یک بار اجرای دستی کنید (`onOpen`). |
| «کد بکاپ پیدا نشد» | مطمئن شوید متن در ستون A و شامل `MCD1.` یا `MCD1z.` است. |
| «کد ناقص یا تغییرکرده است» | کد نصفه کپی شده؛ دوباره از پنل کپی کنید. |
| «توکن اتصال نامعتبر است» | توکن پنل با توکن شیت یکی نیست؛ از منوی «درباره» دوباره بگیرید. |
| ارسال از پنل «انجام نشد» | `Who has access` باید **Anyone** باشد و آدرس باید به `/exec` ختم شود. |
| داده‌ها تکراری شد | هر بکاپ کل شیت‌ها را از نو می‌نویسد؛ تکرار ایجاد نمی‌شود. |

## ۵) اجرای دستی از داخل اسکریپت

اگر خواستید بدون منو تست کنید، در ویرایشگر Apps Script این توابع را اجرا کنید:

```js
setupAll_()              // ساخت/بازسازی همهٔ شیت‌ها
parseBackupCode_(txt)    // فقط خواندن کد و دیدن خروجی
importPayload_(payload, 'test')
```

نتایج هر بکاپ در شیت **«لاگ»** ثبت می‌شود (زمان، منبع، تعداد رکوردها، وضعیت).
